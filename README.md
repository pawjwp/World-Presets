## About

The World Presets mod allows defining world presets, which are templates that modpack authors can make to replace standard world creation. These can be as simple as pre-filled world settings, or as complicated as placing structures, spawning in alternate spawn dimensions, or loading an entire pre-made world. After presets are defined, they will appear in a new tab on the Create World screen.

![The Presets tab](https://raw.githubusercontent.com/pawjwp/World-Presets/refs/heads/main/images/presets-tab.png)

This mod is intended to be played as part of a modpack, it will not change anything until a modpack author configures world presets.

## Features

**[Basic World Settings](https://github.com/pawjwp/World-Presets/wiki/Getting-Started#world-settings)**: Presets can pre-fill most world creation settings, including the world's name, gamemode, difficulty, seed, cheats, and world type.

**[Default Gamerules](https://github.com/pawjwp/World-Presets/wiki/Default-Gamerules)**: Presets can define the default gamerules for the world.

**[Spawn Location](https://github.com/pawjwp/World-Presets/wiki/Spawn-Location)**: Presets can relocate the world spawn location to different coordinates. These can set to an exact coordinate or an offset from spawn, and can be set to run different versions of vanilla's spawn location finder to place the player.

**[Spawn Dimension](https://github.com/pawjwp/World-Presets/wiki/Spawn-Dimension)**: Presets can relocate the world spawn to another dimension. By default, players will respawn in this dimension after death as well, with their spawn dimension relocating whenever their spawnpoint is set in a new dimension. The respawn behavior can be configured in more detail if needed.

**[Starting Structures](https://github.com/pawjwp/World-Presets/wiki/Starting-Structures)**: Presets can spawn structures as the world is created, any [data-defined structure](https://minecraft.wiki/w/Tutorial:Custom_structures) is valid. The placement will attempt to run through the full vanilla structure generation process including proper registration, terrain adaptation, and jigsaw placement.

**[Bundled Worlds](https://github.com/pawjwp/World-Presets/wiki/Bundled-Worlds)**: Presets can include an entire pre-generated world to copy into the player's saves folder. Any world setting changes on the world creation menu like the world name, gamemode, or difficulty are applied onto the existing world.
